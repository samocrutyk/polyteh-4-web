# Акустична варта — лабораторна робота №4

Попередній адаптивний проєкт із лабораторної №3 доповнено зовнішнім JavaScript-файлом `js/monitoring.js`.

## Що реалізовано
- аналіз вимірювань шуму в dB;
- перевірка коректності значень від 30 до 130 dB;
- цикли `for`, `for...of`, `while`, `do...while`;
- `break` і `continue`;
- підрахунок категорій, середнього, мінімуму та максимуму;
- пошук першого критичного вимірювання;
- пошук трьох безпечних вимірювань поспіль;
- Function Declaration, Function Expression та Arrow Function;
- callback-функція;
- підсумковий звіт у Browser Console;
- додаткові тестові набори з умови лабораторної.

Відкрий `index.html` і переглянь результат у DevTools → Console.
