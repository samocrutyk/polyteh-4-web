# Акустична варта — лабораторна робота №3

Адаптивна верстка на основі попередньої HTML/CSS-роботи із використанням SCSS, Flexbox, CSS Grid та Media Queries.

## Структура
- `index.html` — семантична HTML-сторінка
- `scss/` — модульна SCSS-архітектура
- `css/main.css` — скомпільований CSS
- `assets/images/` — каталог для ресурсів

## Breakpoints
- Mobile: `< 768px`
- Tablet: `768–1023px`
- Desktop: `>= 1024px`

## SCSS
Точка входу: `scss/main.scss`. Для повторної компіляції можна використати Sass:

```bash
sass scss/main.scss css/main.css
```
